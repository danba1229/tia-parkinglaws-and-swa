# 주차장 설치비율 체크

`index.html`을 브라우저에서 열면 사용할 수 있는 정적 웹 앱입니다.

## 현재 포함한 내용

- 서울특별시 본조례 디렉터리와 상세 계산 규칙
- 서울 25개 자치구 조례명 디렉터리
- 경기도 31개 시군 조례명 디렉터리
- 주소 입력 시 관할 자동 매칭
- 법정주차대수, 계획주차대수, 기계식 제외 대수 입력 시 유형별 설치비율 계산

## 데이터 범위

- `서울특별시`: 국가법령정보센터 기준으로 직접 확인한 조례 반영
- 직접 확인 또는 2차 출처 스니펫이 확보된 관할은 지역별 상세 규칙으로 구조화
- 나머지 서울 자치구는 `서울 자치구 공통패턴`, 경기도 시군은 `경기도 시군 공통범위`로 계산되도록 보완
- 공통 참고 기준: 주차장법 시행령/시행규칙 및 친환경자동차 관련 상위법 기준

## 사용 방법

1. `index.html`을 더블클릭해서 엽니다.
2. 주소를 입력합니다.
3. 필요하면 `법정주차대수`, `계획주차대수`, `기계식 제외 대수`를 넣습니다.
4. `관할 및 비율 계산` 버튼을 누릅니다.

## 주의

- 자치구·시군별 세부 조문은 아직 전부 구조화하지 못했습니다.
- 앱 안에서 `직접 확인한 공식 출처`, `2차 출처 기반`, `공통패턴·범위 추정`을 분리해서 보여줍니다.
- 실제 인허가 검토 전에는 반드시 해당 관할 최신 조례 원문을 다시 확인하는 것을 권장합니다.
